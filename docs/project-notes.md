# 工作顺序

法源与统一符号基线 → 章节任务及章内分节任务 → 刑诉法衔接 → 汇总与交叉校核。各章任务分别保存范围、输入、交付物、依赖和验收条件；尚未完成的任务保持待办状态。

# 统一交付标准

1. 列出所涉现行条号，包含“之一”等插入条文、删除条文及准用规则。

2. 按条和必要的款项区分构成条件、规范模态、例外、量刑档与竞合。

3. 给出数学或逻辑表达及中文释义，保留需要法律评价的谓词。

4. 标明法源、施行日期、时间效力和地区参数；不同效力类型分别记录。

5. 配置边界例、反例及与总则、刑诉法的交叉引用。

6. 完成覆盖检查后才标记章节交付完成；关键解释未核实者注明待核，不能称已完整核验。
