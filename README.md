# 中华人民共和国刑法数学化

本仓库归档《中华人民共和国刑法》数学化项目的现存可恢复源文件。项目以逐条形式化表达记录构成条件、法律效果、例外、时效和交叉引用，并在选定范围内接入刑事诉讼法与司法解释。

- 各章建模、法源、程序衔接和审查任务见[章节文件](pages/)。
- 合订稿与项目说明见[文档](docs/)。
- 刑法条号覆盖表和定位数据见[数据](data/)。覆盖数据包含 505 个条号节点，其中 1 个为已删除条文的占位。
- 效力区间、证据评价和刑诉法第 55、56 条部分分支见 [Lean 4 候选源码](lean/Core.lean)。原型尚未编译。

归档保留了可取得的章节、稿件和数据。历史 ctexart 原始压缩包和采集原件目前未取得。各版本的范围和未归档文件见[归档说明](docs/archive-scope.md)。
