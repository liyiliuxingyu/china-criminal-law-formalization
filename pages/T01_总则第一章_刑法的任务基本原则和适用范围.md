## 统一符号和适用条件

```text
c = (行为人x, 行为事件e, 行为时间t_act, 地点loc, 事实F, 证据E)
O_A(ψ) = 对机关或主体A而言应当实现法律后果ψ
P_A(ψ) = 主体A依法可以实现ψ；不表示一定选择ψ
F_A(ψ) = 主体A不得实现ψ
Apply(L,c) = 法律L可适用于案件c；不同于已成立犯罪或已证明有罪
Crime_L(c) = 依L及必要的总则派生规则成立犯罪
Prosecutable_L(c) = 依法仍可追诉；不是Crime_L(c)的同义词
v_E(φ) ∈ {真, 假, 未定}；本稿各规则仅在其条件依法得到认定后触发
```

法律评价谓词保持可论证性。事实未查明时不得以“未证明存在例外”直接代替“已证明不存在例外”。目的、定义、权限和罪刑规则采用不同规则类型，不能一律改造成入罪条件。

## 第1条 立法依据与目的

类型：目的及依据元规则。

```text
Basis(刑法) = 宪法
Purpose(刑法) 包含 {惩罚犯罪, 保护人民}
LegislativeContext(刑法) = 我国同犯罪作斗争的具体经验及实际情况
```

本条不直接创设具体犯罪或刑罚。任何依本条目的进行的解释仍受第3条罪刑法定约束，不能从“有利于惩罚犯罪”推出条文之外的犯罪。

边界例：某行为有社会危害但没有可适用的犯罪规定，仅凭本条不能定罪。交叉引用：第3、5、13条。

## 第2条 刑法任务与保护对象

类型：保护目的集合及制度任务。

```text
ProtectedInterests = {
  国家安全,
  人民民主专政政权和社会主义制度,
  国有财产及劳动群众集体所有财产,
  公民私人所有财产,
  公民人身权利、民主权利及其他权利,
  社会秩序、经济秩序,
  社会主义建设事业的顺利进行
}
Task(刑法) = 依法运用刑罚同犯罪行为作斗争以实现上述保护
```

保护对象集合不是可直接加总的“危害分数”。某种利益受损，还须经过分则构成、总则责任和程序证明规则。交叉引用：第13、91、92条及分则各章。

## 第3条 罪刑法定

类型：授权边界及禁止规则。

```text
法律明文规定e为犯罪 ∧ 该规定依法适用于c ∧ 构成与责任条件成立
∧ 有管辖权法院依法审理 ∧ 定罪事实达到法定证明标准
∧ 无依法阻止追究或作有罪判决的事由
  ⇒ O_法院(依照法律定罪并依法处理刑罚)

不存在法律明文犯罪规定适用于e
  ⇒ F_法院(就e创设罪名或法外刑罚)
```

“法律明文规定”须是有权创设刑事规范的法源，不能以普通行政违法、道德评价或相似案件替代。允许的解释须在法律约束内；本规则不把任何扩张解释或类比都先验等同为合法。

公式中的审理、证明和追究条件是与刑诉任务连接的裁判门槛，不是第3条另外增加的犯罪构成要件。仅满足实体犯罪条件不能直接生成有罪判决；第3条确定罪刑法定约束，刑诉法第12、55、200条等控制法院何时可以依法宣告有罪。

边界例：行政规章禁止某行为，不当然使行为构成犯罪。交叉引用：第12、96、101条及刑诉法第12条。

## 第4条 法律面前平等

类型：平等适用约束。

```text
∀x: x实施犯罪 ⇒ O_适法机关(平等适用法律于x)
∀x: F_任何机关(给予x超越法律的特权)

若F1与F2在依法相关事实、适用法和程序条件上等价，
则不得仅因法外身份差异赋予不同的法律适用权限或特权。
```

法律本身规定的主体身份、年龄等差异仍是依法相关变量。平等原则不意味着有不同法定情节的人必须获得相同刑期。交叉引用：第17—19、61、93条。

## 第5条 罪责刑相适应

类型：刑罚结果约束。

```text
PenaltyChosen(c,p)
  ⇒ O_法院(Proportionate(p, 所犯罪行(c), 所承担刑事责任(c)))
```

Proportionate是须结合第61条及有关规范论证的评价谓词，不预设“金额乘系数”“年龄折扣”等数值函数。不允许通过自定权重突破法定刑或法定从宽、从重规则。

边界例：相同财产数额下，犯罪形态、作用和责任能力不同，可以形成不同的合法刑罚集合。交叉引用：第26—29、61—63条。

## 第6条 属地适用

类型：地域适用及地点拟制，分三款。

```text
第1款：WithinTerritory(c) ∧ ¬ApplicableSpecialException(c)
  ⇒ Apply(中国刑法,c)

第2款：CrimeInsideChineseShipOrAircraft(c)
  ⇒ Apply(中国刑法,c)

第3款：ActLocationInTerritory(c) ∨ ResultLocationInTerritory(c)
  ⇒ DeemedWithinTerritory(c)
```

法定“领域”及“中国船舶或者航空器”的识别保留相应法源接口，不用网络服务器位置或国籍的单个字段替代全部地域判断。第2款不要求同时位于中国领域内；第3款中的“或者”不能写成“且”。

边界例：行为在境外、犯罪结果在境内，也可能通过第3款连接中国刑法；是否成立犯罪和由何机关管辖仍分别审查。交叉引用：第7—11条及刑诉法管辖规范。

## 第7条 属人适用

类型：境外中国公民犯罪的适法及可以不追究规则，分两款。

```text
Base7 = ChineseCitizen(x) ∧ CrimeOutsideTerritory(c) ∧ 本法规定该罪
Base7 ⇒ Apply(中国刑法,c)

Base7 ∧ 法定最高刑为三年以下有期徒刑 ∧ ¬SpecialSubject7(x)
  ⇒ P_有权机关(不予追究)

SpecialSubject7(x) = 中国国家工作人员(x) ∨ 中国军人(x)
SpecialSubject7(x) ∧ 境外犯本法规定之罪
  ⇒ Apply(中国刑法,c)
```

“可以不予追究”不等于不适用刑法，也不等于法定必须不起诉；三年以下含三年。第2款主体不适用从第1款一般主体导出的该项境外轻罪宽免。国家工作人员依第93条等识别。

边界例：中国国家工作人员在境外犯最高刑三年的本法罪，不能仅据第1款但书自动不追究。交叉引用：第93条、分则相关条及刑诉法处置权限。

## 第8条 保护管辖

类型：可以适用中国刑法的授权及排除条件。

```text
ForeignPerson(x)
∧ CrimeOutsideTerritory(c)
∧ TargetIsChineseStateOrCitizen(c)
∧ 本法规定的最低刑为三年以上有期徒刑
∧ CrimePunishableUnderPlaceOfCrimeLaw(c)
  ⇒ P_有权机关(Apply(中国刑法,c))

按照犯罪地法律不受处罚
  ⇒ 本条授权不成立
```

这里比较的是最低刑，不是最高刑；三年以上含三年。“可以适用”不能改为所有符合数额条件的案件都必须追诉。具体犯罪地法及其不受处罚含义须依法查明，未查明记未定。

边界例：外国人在境外侵害中国公民，若最低刑门槛不满足，不能仅据本条建立适法权限；但须另查是否存在第6、9条等独立依据。交叉引用：第9、11条。

## 第9条 条约义务范围内适用

类型：条约连接及权限边界。

```text
罪行属于中国缔结或参加的国际条约规定
∧ 中国在所承担条约义务范围内行使刑事管辖权
  ⇒ Apply(中国刑法,c)
```

两项条件须同时存在。不能由“条约提到该行为”直接推出中国法院对任何人、任何地点均有无限管辖权。条约对罪行、属人属地连接、移交和程序的具体条件单列。

边界例：仅有国际文件倡议而没有可适用条约义务或相应刑法依据，不满足本条。交叉引用：第3、6—8条及刑事司法协助规范。

## 第10条 外国审判及已受刑罚

类型：境外裁判不当然阻断中国追究，以及可以免除或减轻处罚。

```text
境外犯罪 ∧ 依本法应当负刑事责任 ∧ 已经外国审判
  ⇒ P_有权机关(依中国刑法追究)

上述条件 ∧ 已在外国受过刑罚处罚
  ⇒ P_法院(免除处罚 ∨ 减轻处罚)
```

外国审判与实际受过刑罚是不同事实。条文没有统一规定按天数机械抵扣全部外国处罚；不把本条任意改成“必须免刑”或一般不再理原则。适用减轻须与第63条衔接。

边界例：仅外国无罪判决、缓诉或行政处理，不当然等同“已经受过刑罚处罚”；其具体效力需核相应法律、条约及案件事实。交叉引用：第63条、条约规则和刑诉程序。

## 第11条 外交特权和豁免权

类型：特殊解决途径。

```text
ForeignPerson(x) ∧ EnjoysDiplomaticPrivilegesAndImmunities(x,c)
  ⇒ O_有权国家机关(通过外交途径解决其刑事责任问题)
```

享有资格、豁免事项、时间范围及有无有效放弃须按适用法和条约判断。不能从“在外国使馆任职”直接推出全部刑事免责，也不能把外交解决写成实体行为合法。

交叉引用：第6—10条、刑诉法第17条及有关外交豁免法律。

## 第12条 刑法时间效力与生效裁判

类型：过渡适法规则及生效裁判效力，分两款。

```text
Domain12 = 新中国成立后、本法施行前的行为
L_old = 行为时法律；L_new = 依法应比较的新法律版本

Domain12 ∧ ¬Crime_L_old(c) ⇒ Apply(L_old,c)，不得以新法追溯入罪

Domain12 ∧ Crime_L_old(c) ∧ 依总则第四章第八节仍应追诉
  ⇒ 默认按L_old追究；但：
     ¬Crime_L_new(c) ⇒ Apply(L_new,c)
     Crime_L_new(c) ∧ PunishmentLighter(L_new,L_old,c) ⇒ Apply(L_new,c)

本法施行前依当时法律已作出的生效判决
  ⇒ 继续有效
```

“处刑较轻”是依适用规则针对具体案件比较的谓词，不等于从所有版本中逐字段挑选最有利数值。第12条直接文本具有特定过渡语境；对其后各修正案和司法解释的适用，应另接相应时间效力规则，不能用本条一段代码替代全部过渡规范。

边界例：旧法不处罚、新法开始处罚，不追溯入罪；旧法已处罚而新法不认为犯罪，尚未形成生效裁判的适法与已经生效裁判的处理不能混同。交叉引用：第87—89条、各修正案施行条款、刑事司法解释时间效力规则。
