## 符号与共通规则

`∧`为且，`∨`为或，`O`为应当，`P`为可以。`T[a,b]`为a至b年有期徒刑；`T≤b`、`T≥a`的另一端依总则期限和例外；`D`拘役、`G`管制、`PP`剥夺政治权利、`J`罚金、`L`无期、`Death`死刑。`∪`是刑罚备选，`⊕`是依法组合，`J-only`是单处罚金。

以下`B`只表示分则局部条件，须调用T01适用法、T02责任和犯罪形态、T03刑罚类型、T04处罚运用以及T17证明程序。刑罚档先依法选择，再适用总则从轻、减轻和死刑限制；不能把达到条文某条件当成法院已判有罪。未完成形态依第22—24条另行判断。未知事实不能默认填假。

本稿刑档表中省略重复的`B_i ∧`或“本条行为成立”时，均以前列本条、相应款的局部行为条件为前提；角色、后果、严重程度条件不能脱离该前提单独产生处罚。

## 第368条 阻碍军人执行职务或武装部队军事行动

```text
B368.1 = 以(暴力 ∨ 威胁)阻碍军人依法执行职务
B368.1 ⇒ O[T≤3 ∪ D ∪ G ∪ J-only]

B368.2 = 故意阻碍武装部队军事行动 ∧ 造成严重后果
B368.2 ⇒ O[T≤5 ∪ D]
```

第一款须“依法执行”，不以军人身份本身替代；第二款不以暴力或威胁为必要方式，但须军事行动和严重后果，不能合并两款的条件。

## 第369条 破坏武器装备军事设施军事通信

```text
B369.I = 故意破坏(武器装备 ∨ 军事设施 ∨ 军事通信)
普通对象且未达特别严重 → T≤3 ∪ D ∪ G
重要武器装备、军事设施或军事通信且未达特别严重 → T[3,10]
情节特别严重 → T≥10 ∪ L ∪ Death

B369.N = 过失实施相应破坏行为 ∧ 造成严重后果
严重后果且非特别严重后果 → T≤3 ∪ D
特别严重后果 → T[3,7]

战时 ∧ (B369.I ∨ B369.N) ⇒ O[依对应规则从重处罚]
```

重要对象与严重结果是不同维度；不得把过失分支省去后果条件。死刑仍受总则限制，战时从重不自动跨档或改判死刑。

## 第370条 提供不合格武器装备军事设施

```text
B370.I = 明知不合格 ∧ 将(武器装备 ∨ 军事设施)提供给武装部队
普通档 → T≤5 ∪ D
情节严重 → T[5,10]
情节特别严重 → T≥10 ∪ L ∪ Death

B370.N = 过失犯相应行为 ∧ 造成严重后果
严重但非特别严重后果 → T≤3 ∪ D
特别严重后果 → T[3,7]

单位犯第一款罪 ⇒ O[单位判J]
                ∧ O[直接负责主管人员和其他直接责任人员依第一款处罚]
```

第三款明确指第一款，不能自行扩成对第二款一律单位双罚。不合格、明知和提供行为须分别证明，不能以事后事故倒推明知。

## 第371条 聚众冲击军事禁区或扰乱军事管理区

```text
B371.1 = 聚众冲击军事禁区 ∧ 严重扰乱该禁区秩序
B371.1 ∧ 首要分子 ⇒ O[T[5,10]]
B371.1 ∧ 其他积极参加 ⇒ O[T≤5 ∪ D ∪ G ∪ PP]

B371.2 = 聚众扰乱军事管理区秩序 ∧ 情节严重
         ∧ 致使管理区工作无法进行 ∧ 造成严重损失
B371.2 ∧ 首要分子 ⇒ O[T[3,7]]
B371.2 ∧ 其他积极参加 ⇒ O[T≤3 ∪ D ∪ G ∪ PP]
```

军事禁区和军事管理区分开定义。第二款四个条件合取；条文明定处罚角色不能扩张成所有在场者。

## 第372条 冒充军人招摇撞骗

```text
B372 = 冒充军人 ∧ 招摇撞骗
B372 ∧ ¬情节严重 ⇒ O[T≤3 ∪ D ∪ G ∪ PP]
B372 ∧ 情节严重 ⇒ O[T[3,10]]
```

单纯穿着相似服饰、身份误解或一般夸称，不可跳过招摇撞骗的行为与主观认定。财产诈骗、证件或专用标志犯罪竞合需另核，不预设统一择重。

## 第373条 煽动军人逃离部队或雇用逃兵

```text
A373 = 煽动军人逃离部队
       ∨ (明知对方是逃离部队的军人 ∧ 雇用该人)
B373 = A373 ∧ 情节严重
B373 ⇒ O[T≤3 ∪ D ∪ G]
```

“明知”明确修饰雇用分支，严重情节适用于整体行为分支。不能以雇用退役军人代替雇用逃离部队的军人。

## 第374条 征兵工作徇私舞弊接送不合格兵员

```text
B374 = 在征兵工作中 ∧ 徇私舞弊 ∧ 接送不合格兵员
普通入罪档：B374 ∧ 情节严重 ⇒ O[T≤3 ∪ D]
加重档：B374 ∧ 造成特别严重后果 ⇒ O[T[3,7]]
```

特别严重后果另依法判断，不能按损失数值随意自定。征兵职责、不合格标准、徇私舞弊与接送行为各需证据。

## 第375条 军队公文证件印章服装和专用标志

```text
B375.1 = (伪造 ∨ 变造 ∨ 买卖 ∨ 盗窃 ∨ 抢夺)
         武装部队(公文 ∨ 证件 ∨ 印章)
普通档 → T≤3 ∪ D ∪ G ∪ PP
情节严重 → T[3,10]

B375.2 = 非法(生产 ∨ 买卖)武装部队制式服装 ∧ 情节严重
S375.2 = ((T≤3 ∪ D ∪ G) ⊕ J) ∪ J-only
B375.2 ⇒ O[依S375.2处罚]

B375.3 = (伪造 ∨ 盗窃 ∨ 买卖 ∨ 非法提供 ∨ 非法使用)
         武装部队车辆号牌等专用标志
情节严重且非特别严重 → ((T≤3 ∪ D ∪ G) ⊕ J) ∪ J-only
情节特别严重 → T[3,7] ⊕ J

单位犯第二或第三款 ⇒ O[单位判J]
                 ∧ O[直接负责主管人员和其他直接责任人员依各该款处罚]
```

第一款没有明示单位双罚；第二、三款“并处或者单处罚金”不包含仅判主刑而完全不判罚金的组合。物品是否属于武装部队正式制式、专用标志须核定，不能泛化为任何迷彩或军风商品。

## 第376条 战时拒绝逃避征召训练或服役

```text
B376.1 = 预备役人员 ∧ 战时 ∧ (拒绝 ∨ 逃避)(征召 ∨ 军事训练)
         ∧ 情节严重
B376.1 ⇒ O[T≤3 ∪ D]

B376.2 = 公民 ∧ 战时 ∧ (拒绝 ∨ 逃避)服役 ∧ 情节严重
B376.2 ⇒ O[T≤2 ∪ D]
```

平时行为不能删除“战时”后直接套用本条；征召、训练和服役的法定具体义务由适用兵役规范接口确定。

## 第377条 战时提供虚假敌情

```text
B377 = 战时 ∧ 故意向武装部队提供虚假敌情
B377 ∧ 严重后果且非特别严重后果 ⇒ O[T[3,10]]
B377 ∧ 特别严重后果 ⇒ O[T≥10 ∪ L]
```

错误信息、故意虚假和后果归责不混同。没有严重后果时，本条既遂结果条件不满足，是否涉及其他犯罪另行判断。

## 第378条 战时造谣惑众扰乱军心

```text
B378 = 战时 ∧ 造谣惑众 ∧ 扰乱军心
B378 ∧ ¬情节严重 ⇒ O[T≤3 ∪ D ∪ G]
B378 ∧ 情节严重 ⇒ O[T[3,10]]
```

“谣”“惑众”“扰乱军心”分别保留评价与证明，不从一般错误表达自动推导完整犯罪。

## 第379条 战时窝藏逃离部队军人

```text
B379 = 战时 ∧ 明知对方为逃离部队军人
       ∧ 向其提供(隐蔽处所 ∨ 财物) ∧ 情节严重
B379 ⇒ O[T≤3 ∪ D]
```

不知军人逃离状态、不属于逃离部队者或一般退役人员，不得仅因帮助住宿而填入本条。对明知的推断须通过证据链而非关系标签。

## 第380条 战时拒绝故意延误军事订货

```text
B380 = 战时 ∧ (拒绝 ∨ 故意延误)军事订货
B380 ∧ 情节严重 ⇒ O[单位判J]
                    ∧ O[直接负责主管人员、其他直接责任人员判T≤5 ∪ D]
B380 ∧ 造成严重后果 ⇒ O[单位判J]
                       ∧ O[上述责任人员判T≥5]
```

这是条文明确的单位及责任人员结构，不应生成没有单位要件的统一自然人犯罪公式。客观不可履行与故意延误须区别，订货性质、战时义务及后果归责均须核实。

## 第381条 战时拒绝军事征收征用

```text
B381 = 战时 ∧ 拒绝依法适用的(军事征收 ∨ 军事征用)
       ∧ 情节严重
B381 ⇒ O[T≤3 ∪ D]
```

征收征用的权限、决定与义务来源须由适用法律核定；不能把任意民间提出的交付要求当成军事征收征用。
