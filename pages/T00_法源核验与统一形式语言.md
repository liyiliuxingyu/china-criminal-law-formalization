## 底本与规范类型

刑法底本采用[国家税务总局政策法规库所载、沿革整合至修正案十二的刑法正文](https://fgk.chinatax.gov.cn/zcfgk/c100009/c5212248/content.html)。修正案十二自2024年3月1日施行；这一日期属于该修正案，不能把刑法所有历史条文的生效时间统一重置为2024年。历史行为仍须按第12条及有关过渡、解释时间效力规则选法。

~~~text
RuleKind ∈ {
  purpose, offence, stage_derivation, liability, penalty,
  definition, legal_fiction, reference, concurrence, unit_liability,
  jurisdiction, procedure, evidence, execution, temporal, repealed
}

ArticleID = (基本条号, 插入序号)
例如：17=(17,0)，17之一=(17,1)，262之二=(262,2)。
按数字元组排序，不按字符串顺序排序。

Rule = (id, kind, subject, guard, modality, effect,
        exceptions, references, scope, source_version)

SourceVersion = (文件名, 文号, 效力类型, 具体条款,
                 公布日期, 施行日期, 失效或修改日期,
                 过渡规则, 地区, 官方URL, 核验状态)
~~~

法律、全国人大常委会立法解释、司法解释、指导意见及指导性案例分别记录。立法解释和司法解释不能混成一种文件；普通指导性文件不因发布时间较新便自动优先于法律。冲突处理依有权法源、适用范围、特别规定及时间效力逐项判断，不能用一条“日期最大者胜出”的规则。

## 基本符号与模态

~~~text
c = (主体x, 行为事件e, 行为时间t_act, 地点loc, 事实F, 证据E)
∧ = 且；∨ = 或；¬ = 否；⇒ = 规范条件成立后的推导。
O_A(ψ) = 主体或机关A应当实现ψ。
P_A(ψ) = A依法可以选择ψ，不表示一定选择。
Forbid_A(ψ) = A不得实现ψ。
本书某章使用F(ψ)表示不得时，应按此模态读取，不能与事实集合F混淆。

应当从轻、减轻或者免除
  ⇒ O(从轻 ∨ 减轻 ∨ 免除)，不是三项全部实施，也不是任意固定折扣。
可以从轻或者减轻
  ⇒ P(从轻 ∨ 减轻)，不是O(减轻)。
~~~

“可以认定”保留认定裁量及综合评价条件；“应当认定”保留其前提事实与适用法要求。“之一”通常建立备选分支；其中每个分支内部的合取条件不得丢失。法条中的但书、除外、特别规定、转致和竞合均单列，不能缩入不透明的“符合本条”谓词。

法律评价词如情节严重、重大损失、必要限度、确有悔改表现保留为有出处的评价谓词。已经有司法解释量化的部分可以进一步展开；未经核实的标准以参数表示并加入待核表，不由模型自行赋值。

## 事实证明与实体评价分层

~~~text
v_E(φ) ∈ {真, 假, 未定}。
¬未定 = 未定；未证明φ ≠ 已证明¬φ。
未定∧假=假；未定∧真=未定；未定∨真=真；未定∨假=未定。

Applicable(r,c) = r对该主体、时间、地域和事项依法适用。
Applicable(r,c) ∧ guard_r(c) ∧ 不存在依法适用的例外
  ⇒ modality_r(effect_r(c))。
~~~

上述三值运算是记录证据状态的形式化约定，不是用技术逻辑重新分配法律证明责任。尤其不能通过“例外未获证明”自动推定对被告人不利的否定条件成立。公诉、自诉的有罪举证责任及证据规则另见T17。

~~~text
ApplyLaw(c) ≠ Crime(c) ≠ Prosecutable(c)
            ≠ Convictable(c) ≠ ExecutablePenalty(c)。
~~~

犯罪成立、尚可追诉、达到定罪证明标准及能够执行刑罚分别输出。免予刑事处罚与无罪判决不同；证据不足的无罪判决也不表示全部相反事实已被证明。不得以立案、逮捕或起诉状态替代犯罪构成和有罪判决。

## 犯罪形态与总则的组合接口

~~~text
Completed_g(c) = 本罪要求的主体、主观与客观完成条件成立。
CompleteLiability_g(c) = Completed_g(c)
  ∧ 本罪责任条件 ∧ ¬正当化事由 ∧ ¬第13条显著轻微排除。

Preparation_g(c) = 为了实施g而准备工具或制造条件，
  并经形态划分与特别规范审查仍处预备阶段。
Attempt_g(c) = 已着手实施g ∧ 未得逞 ∧ 意志以外原因。
Discontinuance_g(c) = 犯罪过程中
  ∧ (自动放弃犯罪 ∨ 自动有效防止犯罪结果)。

LiabilityByStage_g(c,s) = 该罪依法允许适用形态s
  ∧ 该形态自己的成立条件 ∧ 主体与主观归责条件
  ∧ 责任条件 ∧ 无正当化或其他法定排除。
~~~

不能先强制要求所有既遂条件成立，再在量刑阶段给未遂“打折”。具体犯罪的既遂条件和预备、未遂追究范围可能受特别规范限制。中止未造成损害依法免除处罚，仍与一开始不构成犯罪的结果不同。罪过、年龄、能力、共同归责及单位责任接口分别由T02提供。

12—14周岁规则拆分为实体责任范围与最高检核准追诉门槛；最终追究必须满足二者，但核准这一程序权限不能改写成出生年龄的一部分。所有年龄和身份变量必须带法条要求的时间点，例如行为时、审判时等，不能全书只用一个age字段。

## 刑罚类型与组合运算

~~~text
Main = Control(d) | Detention(d) | Term(d) | Life | Death(mode)。
Additional = Fine(amount) | PoliticalRights(d或终身) | Confiscation(scope)。
Penalty = (main或空值, additional集合)。
驱逐出境按第35条另设特别适用接口。

OR(X,Y) = X∪Y。
AND(X,Y) = {x⊕y : x∈X且y∈Y且组合依法相容}。
OPT(Y) = {不附加该项}∪Y。

甲或者乙                  = OR(甲,乙)
甲并处乙                  = AND(甲,乙)
甲可以并处乙              = AND(甲,OPT(乙))
甲并处或者单处乙          = AND(甲,乙)∪单处乙
甲并处罚金或者没收财产    = AND(甲,OR(罚金,没收财产))
~~~

同一罪的两个备选主刑不能用AND同时判处；数罪并罚另交第69—71条算子。附加刑可独立适用不等于任何罪均可任意单处罚金或没收财产。各罪本条还须叠加总则的附加刑规定。第64条追缴、退赔、返还及物品没收另设财物处置字段，不与第59条没收财产刑混同。

~~~text
Base_g(c) = 依法选择的罪名及法定刑分支对应的刑罚组合集合。
S(c) = ApplyGeneralAndSpecialRules(Base_g(c),责任及情节,适用法)。
判决刑罚p ∈ S(c)，并给出选择与裁量理由。
~~~

较高金额分支通常同时满足较低金额条件，不能因此把所有档位无条件取并集；先依法选档，再处理从轻、从重、减轻、免除等。减轻会变换可选集合，不是单纯给原档求交。无期与死刑不是固定年数或无穷年；实际执行下限也不是自动释放时间。

## 全书符号命名空间

每章构成独立符号作用域。章节之间通过条文编号、规则编号和语义类型接口调用；不能把甲章的局部字母释义直接套到乙章。全局刑罚接口统一使用 Control、Detention、Term、Life、Death、Fine、PoliticalRights、Confiscation。

| 局部符号 | 全局语义 |
| --- | --- |
| T08::B、T11::D | Detention，拘役 |
| T08::D、T11::X | Death，死刑 |
| T08::G、T11::G | Control，管制 |
| T08::L、T11::L | Life，无期徒刑 |
| T08::T、T11::T | Term，有期徒刑 |
| T08::F、T11::F | Fine，罚金 |
| T08::M、T11::M | Confiscation，没收财产刑 |

其他章节的局部符号同样依其章首字典解释。形如T08::D的写法表示T08作用域内的D；物理合并文件不取消这个作用域。对另一条文的准用调用被引用规则的完整语义，不对其内部字母作调用章的重新解释。该约定解决首稿合并中的同字异义，不能以字符串替换代替法律后果比较。
