1. 逐条登记现行条号，包含插入条号、款项、删除占位、定义、准用、单位责任、竞合与适用范围条款。每条应有对应规则，不以章节概述替代。

## 实体、证明、追诉与执行的接口

~~~text
Case c=(主体,行为事件,行为时间,地点,事实命题F,证据E)。
Substantive_g(c) = 按适用刑法及犯罪形态派生规则可成立罪g。
Prosecutable(c) = 尚有依法追究责任的实体及程序条件。
EvidenceSufficient_g(E) = 针对罪g的待证事实达到法定证明要求。
Adjudicable(c,q) = 在程序状态q有权依法进行相应审判。
Executable(c,p) = 刑罚或其他裁判已满足相应生效、交付及执行条件。

这五个字段分别保存，不互相用一个布尔值替代。
~~~

刑诉法第12条的约束是：未经人民法院依法判决，不得对任何人确定有罪。立案、采取强制措施、检察机关起诉或模型产生候选罪名，都不能越过这一约束。

## 举证责任与事实状态 第50—55条

~~~text
v_E(φ) ∈ {依法认定真, 依法认定假, 未定}。
¬未定=未定。

公诉案件有罪举证责任主体=人民检察院。
自诉案件有罪举证责任主体=自诉人。

收集案件证据 ⇒ O(依照法定程序同时收集有罪/无罪、罪重/罪轻材料)。
Forbid(刑讯逼供及法定禁止的其他非法取证)。
Forbid(强迫任何人证实自己有罪)。
~~~

证据类型分别记录物证、书证、言词证据、鉴定意见、有关笔录、视听资料与电子数据等。材料须查证属实才可作为定案根据，不因“已写入数据库”便获得真实性或证明力。

~~~text
BRD(E,Fg) =
  定罪量刑的相关事实均有证据证明
  ∧ 据以定案的证据均经法定程序查证属实
  ∧ 综合全案证据对所认定事实已排除合理怀疑。

只有被告人供述 ∧ 没有其他证据
  ⇒ Forbid(据此认定有罪) ∧ Forbid(据此处以刑罚)。
没有被告人供述 ∧ 其余证据达到法定标准
  ⇒ P(依法认定有罪并处刑)。
~~~

BRD是法定综合证明标准，不设P(有罪|证据)>95%之类数值阈值。事实未定由证明责任和具体规则处理；不得要求被告人通过一个通用规则证明所有无罪事由。疑点指向关键罪责事实且依法不能排除时，不能输出有罪判决。

## 非法证据排除 第56—60条

~~~text
TortureStatement = 刑讯逼供等非法方法取得的嫌疑人/被告人供述。
ViolentWitnessStatement = 暴力、威胁等非法方法取得的证言或被害人陈述。
TortureStatement ∨ ViolentWitnessStatement ⇒ O(排除)。

PhysicalDocumentDefect = 物证/书证收集不符合法定程序
                        ∧ 可能严重影响司法公正。
PhysicalDocumentDefect ⇒ O(补正 ∨ 作出合理解释)。
PhysicalDocumentDefect ∧ ¬(能够依法补正 ∨ 能够作出合理解释)
  ⇒ O(排除)。

法庭调查证据收集合法性 ⇒ O_检察机关(证明收集合法性)。
经法庭审理确认或者不能排除第56条非法取证情形
  ⇒ O(排除有关证据)。
~~~

电子数据、鉴定等其他种类有相应专门规范接口，不能不分种类将第56条所有分支机械套用。证明力与证据资格也是两个字段：被排除的材料不得作相应决定依据；具备证据资格不等于单独足以证明犯罪。

程序边界例：被告人提出相关线索触发合法性调查，不等于最终已确认刑讯；但法庭调查后仍不能排除法定非法取证情形时，不能把未定自动转成合法。本类不利后果有第60条的特别分配依据。

## 追诉与处理结果 第16、112、176、177、200条

~~~text
Disposition ∈ {
  不予立案, 撤销案件, 不起诉, 终止审理,
  法律认定无罪判决, 证据不足无罪判决,
  有罪免予刑事处罚, 有罪并依法处刑, 其他法定结果
}。

StageResult = DecideDisposition(程序阶段,有权机关,事实,证据,适用规范)。
~~~

刑诉法第16条列举显著轻微不认为犯罪、超过追诉时效、特赦、告诉才处理但无告诉或撤回、死亡及其他法定情形。各情形依当前程序阶段及特别规定，进入撤案、不起诉、终止审理或无罪等路径，不能统一标成一个“无罪”值。死亡案件存在依法确认无罪等特别路径，也不能无条件覆盖为终止。

~~~text
处于审查起诉阶段 ∧ 检察机关审查认为犯罪事实已查清 ∧ 证据确实充分
  ∧ 依法应追究刑事责任 ∧ 无依法适用的不起诉等其他处理分支
  ⇒ O(依法提起公诉)，并适用第176条程序要求。

处于检察机关依法可以作不起诉决定的审查起诉阶段
  ∧ (没有犯罪事实 ∨ 有第16条情形)
  ⇒ O_检察机关(不起诉)。
处于上述审查起诉阶段 ∧ 犯罪情节轻微 ∧ 依刑法不需要判刑或免除刑罚
  ⇒ P_检察机关(不起诉)，不是当然实体无罪。

法院审理事实清楚 ∧ 证据确实充分 ∧ 依法认定有罪
  ⇒ O(有罪判决)。
法院依据法律认定无罪 ⇒ O(无罪判决)。
法院审理证据不足 ∧ 不能认定有罪
  ⇒ O(证据不足、指控不能成立的无罪判决)。
~~~

不起诉的法定、裁量和存疑等具体路径须保持各自根据。刑法第37条免予处罚等进入有罪判断后的刑罚处置，不能反向改写成刑诉法第200条第2项的实体无罪。

## 管辖、权限与强制措施

~~~text
q=(阶段,有权机关,案件管辖,强制措施,期间账本,诉讼权利状态)。

q --程序行为a--> q' 合法
  当且仅当该行为具有法定权限、适用条件、期限与必要权利保障。
~~~

刑诉法第19—28条等将侦查管辖、法院级别和地域管辖分别规定；自诉、专门法院及指定管辖另有接口。刑法可适用中国法律，与某一具体机关有管辖权，不是同一命题。

拘传、取保候审、监视居住、拘留和逮捕分别设状态与条件。逮捕的第81条规则不能由“涉嫌罪名较重”一个字段替代；一般条件、社会危险性判断及法定特别分支须按适用规范展开。羁押必要性审查、期限届满释放或变更措施另有第95—99条接口。

边界例：有证据足以立案，不当然有足够条件逮捕，更不表示达到定罪证明标准。取保候审也不等于已认定无罪。各具体证明要求保留阶段参数，不把BRD无条件强加为所有侦查行为的统一前置条件。

## 期间计算 第105—107条及各专门期限

~~~text
Period = (起算事件,单位,长度,是否计开始时日,
          不计入区间,延长权限,重算事件,届满规则)。

单位∈{时,日,月}；开始的时、日不计入期间。
法定期间不计路途时间；期满前已交邮的文件不算过期。
一般期间最后一日为节假日 ⇒ 届满日顺延至节假日后第一日。
在押期间 ⇒ 至依法计算的期满日为止，不得因节假日延长。

当事人因不能抗拒原因或其他正当理由耽误期限
  ∧ 障碍消除后5日以内提出申请
  ⇒ P(申请继续进行相应诉讼活动)；是否准许由法院裁定。
~~~

不得统一换算一个月为30日，也不能把中止、延期、延长、不计入和重新计算合成“暂停计时”。例如第208条改变管辖、补充侦查移送后的重新计算，与第206条中止审理期间不计入，是不同事件和依据。

送达独立保存收件人、代收资格、送达方式、确认事实、日期和特别适用根据。普通送达第107条与境外缺席审判第292条规则分别调用。

## 认罪认罚 第15、201条

~~~text
VoluntaryAdmission = 自愿如实供述罪行
  ∧ 承认指控的犯罪事实 ∧ 愿意接受处罚。
VoluntaryAdmission ⇒ P(依法从宽处理)。

认罪认罚案件 ∧ 无第201条例外
  ⇒ 一般应当采纳检察机关指控罪名及量刑建议。
~~~

第201条例外包括行为不构成犯罪或不应追责、违背意愿认罪认罚、否认指控事实、起诉罪名与审理认定不一致及其他可能影响公正审判情形。量刑建议明显不当或者被告人、辩护人提出异议时，进入检察机关可以调整、法院依法裁判的路径，不能把量刑建议当作约束法院的固定数值。

认罪认罚不降低法定有罪证明标准，也不能自动推出固定减刑百分比。具体指导意见、具结与律师帮助等细节须接入相应现行配套规范；本稿不把未经完整核验的旧指导意见内容标成现行全量规则。

## 普通及特别程序状态机

~~~text
普通公诉：受案审查→立案→侦查→审查起诉→公诉→一审→依法生效/二审→执行。
监察移送：依法调查→移送检察机关→审查起诉及相应衔接程序。
自诉：直接起诉法院→受理审查→审判；不强制经过公安侦查路径。
未成年人：普通节点上叠加专门权利保障、分流与记录规则。
和解：只有法定案件范围及条件满足才进入和解及从宽路径。
死刑：相应裁判→法定复核/核准→依法交付；不以两审终结自动替代复核。
逃匿/死亡违法所得没收：财产特别程序，不能用其财产裁定替代对人的有罪判决。
强制医疗：依法不负刑责精神病人的法定行为、危险及程序条件→法院决定；不是刑罚。
~~~

每个转换都有拒绝受理、撤案、不起诉、补充、退回、终止或恢复等法定分支。简易、速裁程序属于条件受限的程序选择，不能因模型算得快而自行适用。未成年人附条件不起诉、记录封存，和解范围，死刑复核和强制医疗等详细条件应逐项连接专门规范；本稿建立了接口，不宣称已经完成这些特别程序的全部款项。

## 缺席审判的2025—2026衔接

刑诉法第291—297条规定若干不同缺席路径，不是一切被告人未到庭均可直接缺席定罪。对第291条第1款境外案件，案件范围、必要核准、管辖、送达和辩护等条件必须分别审查。[刑诉法特别程序](https://www.samr.gov.cn/zw/zfxxgk/fdzdgknr/bgt/art/2025/art_48b3b0c3f954448e996602a71fc6f878.html)

~~~text
OtherAllowedService292(method,country)=
  被告人所在地的法律、判例、惯例或司法实践等
  对该方式规定、承认、认可或接受。

OtherAllowedService292可以包含邮寄、公告、公示、电子等；
  但不能仅因中国法允许某方式就省去所在地允许条件。
~~~

上述含义来自2025年12月27日全国人大常委会解释，2026缺席规定第8条进一步列示方式及其条件。2026规定第9条还要求相应辩护保障；第14条明确缺席有罪判决同样须事实清楚、证据确实充分。

~~~text
第291条第1款路径的缺席审理中被告人到案
  ⇒ O(裁定终止审理)；依法重新公诉受理后重新审理。

相应缺席判决/裁定生效后到案
  ⇒ 交付执行前O(告知有权提出异议)。
t_notice=被告知有权提出异议的时点。
在t_notice后法定10日以内提出异议
  ⇒ O(原审法院撤销原判决/裁定并通知检察机关)。
检察机关依法提起公诉后 ⇒ O(依法重新审理)。
~~~

这里10日从告知异议权后起算，不从境外被控制、入境或裁判原生效日任意起算。严重疾病缺席审理、死亡无罪确认和审判监督的缺席审理还适用不同分支，不由上述第16条流程全局覆盖。[2026缺席审判规定第14—24条](https://www.court.gov.cn/zixun/xiangqing/500781.html)

## 2026民刑交叉接口补充

法源为[最高法《关于审理涉及刑事犯罪的民事纠纷案件若干问题的规定》](https://www.court.gov.cn/zixun/xiangqing/512441.html)，**法释〔2026〕19号**，2026年9月20日落款、9月21日官网发布、9月22日施行。第24条规定此前最高法司法解释冲突时以本规定为准。民事责任仍依民法典等适用实体法判断，以下程序接口本身不自动产生赔偿义务。

```text
SameFact = 民事与刑事案件的当事人、基本事实相同      # 第2条
RelatedNotSame = 与犯罪行为有关联但非同一事实

RelatedNotSame ∧ 第3条列举的请求类型
    ⇒ O[依法受理民事诉讼]
依第3条受理 ⇒ O[民刑分别审理]                      # 第4条原则
依第3条受理 ∧ 民事基本事实必须以刑事审理结果为依据
            ∧ 刑事案件尚未审结
    ⇒ O[依法中止民事诉讼]
中止原因消除 ⇒ O[及时恢复诉讼]
```

第3条列举包括请求未构成犯罪的法人、非法人组织或他人承担相关合同/职务侵权责任、请求非共犯担保人承担责任、部分债务人犯罪时请求其他债务人承担责任、侵权犯罪所涉保险金及其他关联非同一事实请求。刑事受案回执、刑事立案本身不自动满足中止或移送条件；第5条要求审查具体事实关系。

```text
生效刑事裁判已认定事实
    ⇒ 民事诉讼中无须另行举证证明
    但相反证据足以推翻时进入第6条的函告、必要上报程序

事实未达刑事证明标准而未获认定
∧ 经民事审查达到民事证明标准
    ⇒ P[依法在民事诉讼中认定]                      # 第8条
```

后式绝不倒推“民事认定即可刑事定罪”，也不表示无罪者当然承担民事责任。民事实体要件和证明要求须各自满足。第7条关于未作刑事定案根据的言词材料，要求其未被作为非法证据排除，再依法组织民事质证决定是否采信，不是所有刑事材料直接移用。

```text
依法不追究刑事责任的第15条情形
∧ 当事人基于同一事实提起民事诉讼
    ⇒ O[依法受理]
相关民事责任 ⇒ 按民法典等法律独立认定
```

第15条包括不立案、撤案、不起诉、生效无罪或不负刑责裁判及其他依法不追究情形。第16条被告人行为不构成犯罪时，附带民事可调解，调解不成可一并作出刑事附带民事判决，民事责任依民法典等判断。第17条规定犯罪关联合同的效力及其是否对被代理人发生效力，应依法独立判断；不能统一设为“犯罪则合同无效”。

第9条对其适用请求中已经刑事追缴、责令退赔返还或赔偿的部分，依法支持相应扣减，避免重复受偿。第11条单位涉刑不当然阻断依法受理破产及民刑分别进行。非法集资等有特别规定的，依第23条优先接口处理；本补充不以一般接口覆盖全部特别制度。

边界：未达到排除合理怀疑不等于民事事实必定不成立；刑事立案不等于民事自动中止；不追刑责不等于民事赔偿必然成立或必然消灭；刑事已追回金额不应在民事执行中无条件重复取得。

## 2026认罪认罚指导意见补充

已打开[最高法完整正文](https://www.court.gov.cn/zixun/xiangqing/506411.html)：**高检发〔2026〕5号**，五部门通知落款2026年4月30日，官网发布2026年7月17日；第71点规定自发布之日起施行，并将高检发〔2019〕13号指导意见同时废止。记录印发落款、官网发布时间和“自发布之日”条款，避免把三者默认为同一日期。它是司法规范性指导意见，不标为法释类司法解释。

本轮仅细化已经核对的主要接口，未声称71点全量编码：

```text
认罪认罚 ⇒ 不降低侦查终结、起诉、有罪裁判的法定证明标准      # 第3点
单位诉讼代表人代表单位自愿如实供述单位犯罪事实
∧ 积极协助调查 ∧ 自愿接受处罚 ⇒ P[对涉案单位从宽]          # 第6点
单位直接责任人员的认罪认罚及从宽另行判断，不由单位供述自动替代

数罪仅供述部分事实 ⇒ 全案不作认罪认定、不适用全案认罪认罚制度
                    但对如实供述部分P[依法从宽]             # 第7点
不同意速裁或简易程序 ⇏ 不认罚                             # 第8点
认罪认罚适用须保障自愿性、真实性、合法性和辩护法律帮助        # 第9点
认罪认罚与自首、坦白 ⇒ 不重复评价同一从宽事实                # 第11点
部分共同犯罪人员认罪认罚 ⇒ P[对相应人员从宽]，逐人评价责任    # 第12点
```

第30—34点对具结、辩护人在场、异议记录、具结效力及量刑建议有具体规则；第46点不允许简单以认罪与不认罪作为共同犯罪分案标准。第47—49点要求审查量刑建议、不采纳时说理及法定调整程序，不能由签具结书推出法院必判建议数值。其余完整分支及边界仍保留后续核验任务。
