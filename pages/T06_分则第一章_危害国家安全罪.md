## 统一符号与调用约束

`∧`为且，`∨`为或，`¬`为非；`O`为应当，`P`为可以。`T[a,b]`表示a至b年有期徒刑，`T≤b`、`T≥a`的另一端受总则通常期限和特别规定约束；`D`为拘役，`G`为管制，`PP`为剥夺政治权利，`L`为无期徒刑，`Death`为死刑，`F`为没收财产。`∪`表示刑罚备选，`⊕`表示依法组合，`Opt(F)={不附加F,F}`。

以下`B_i`是分则局部行为条件，不是已证明有罪的结论。每个规则还须调用总则适用范围、责任主体、罪过、正当化事由、第13条但书、未完成形态及刑诉证据程序接口。`B_i`涉及既遂结果时，未遂、预备、中止通过第22—24条另行派生，不能只在满足全部既遂条件后调整刑罚。未知事实不自动当作例外不存在。

处罚记作`B ⇒ O[依法在S中量刑]`，不是任选不受约束的随机集合。法定特别档先依法确定，再适用从轻、减轻等规则。死刑禁止、减轻处罚等须用总则变换处理，不能仅将集合机械取交。依第56条，危害国家安全罪的政治权利效果另行加载；本条以独立适用PP作为备选处罚时不再重复附加同一效果；PP仍是附加刑的类型，独立适用不使其变为主刑。

本稿刑档表中省略重复的`B_i ∧`或“本条行为成立”时，均以前列本条、相应款的局部行为条件为前提；角色、后果、严重程度条件不能脱离该前提单独产生处罚。

## 第102条 勾结境外力量危害主权领土安全

```text
B102.1 = 勾结外国 ∧ 危害中华人民共和国主权、领土完整和安全
B102.2 = 勾结境外机构、组织或个人 ∧ 实施B102.1所指危害行为
S102 = T≥10 ∪ L
(B102.1 ∨ B102.2) ⇒ O[依S102处罚]
```

第二款是相同处罚的扩展连接点，不能误写为“只要与境外人员接触即可定罪”。“勾结”“危害”各自需要事实及法律评价；本条罪名的完整主体解释与国籍边界列为待核接口。

## 第103条 分裂国家及煽动分裂国家

```text
B103.1 = (组织 ∨ 策划 ∨ 实施)分裂国家、破坏国家统一
B103.1 ∧ (首要分子 ∨ 罪行重大) ⇒ O[T≥10 ∪ L]
B103.1 ∧ 积极参加且未进入前档 ⇒ O[T[3,10]]
B103.1 ∧ 其他参加 ⇒ O[T≤3 ∪ D ∪ G ∪ PP]

B103.2 = 煽动分裂国家、破坏国家统一
B103.2 ∧ ¬(首要分子 ∨ 罪行重大) ⇒ O[T≤5 ∪ D ∪ G ∪ PP]
B103.2 ∧ (首要分子 ∨ 罪行重大) ⇒ O[T≥5]
```

两款分别建模；角色、罪行重大不是单一人数评分。第113条排除第103条第二款的死刑适用，第106条可能对境外勾结情形从重。

## 第104条 武装叛乱或武装暴乱

```text
B104.1 = (组织 ∨ 策划 ∨ 实施)(武装叛乱 ∨ 武装暴乱)
首要分子 ∨ 罪行重大 → T≥10 ∪ L
积极参加且非前档 → T[3,10]
其他参加 → T≤3 ∪ D ∪ G ∪ PP

B104.2 = (策动 ∨ 胁迫 ∨ 勾引 ∨ 收买)
         (国家机关工作人员 ∨ 武装部队人员 ∨ 人民警察 ∨ 民兵)
         进行(武装叛乱 ∨ 武装暴乱)
B104.2 ⇒ O[依第一款相应角色/罪行情形处罚并从重]
```

第二款主体对象和行为方法均须保留。不得将“从重”写成跨越法定刑档的固定加年。

## 第105条 颠覆国家政权及煽动颠覆

```text
B105.1 = (组织 ∨ 策划 ∨ 实施)颠覆国家政权、推翻社会主义制度
首要分子 ∨ 罪行重大 → T≥10 ∪ L
积极参加且非前档 → T[3,10]
其他参加 → T≤3 ∪ D ∪ G ∪ PP

B105.2 = 通过(造谣 ∨ 诽谤 ∨ 其他方式)
         煽动颠覆国家政权、推翻社会主义制度
普通档 → T≤5 ∪ D ∪ G ∪ PP
首要分子 ∨ 罪行重大 → T≥5
```

必须证明相应行为的法定性质和故意，不从一般表达、批评或争议直接推出本罪。第113条将第105条全部排除在其特别死刑授权外。

## 第106条 境外勾结从重规则

```text
B106 = 与境外机构、组织或个人勾结
       ∧ 已成立第103条、第104条或第105条之罪
B106 ⇒ O[依对应罪条从重处罚]
```

本条属于附着于基础犯罪的从重规则，不产生一个可以另行数罪并罚的独立“第106条罪”。

## 第107条 资助危害国家安全犯罪活动

```text
Target107 = 实施第102、103、104、105条所定之罪的活动
B107 = 境内外机构、组织或个人资助Target107
Person107 = 对该资助行为负直接责任的人员
B107 ∧ Person107 ∧ ¬情节严重 ⇒ O[T≤5 ∪ D ∪ G ∪ PP]
B107 ∧ Person107 ∧ 情节严重 ⇒ O[T≥5]
```

不能把资助任何境外机构概括为本条行为。条文规定直接责任人员刑责，不得自行增加对单位判处罚金的双罚分支。第113条不授权本罪适用死刑。

## 第108条 投敌叛变

```text
B108 = 投敌叛变
High108 = 情节严重
          ∨ 带领(武装部队人员 ∨ 人民警察 ∨ 民兵)投敌叛变
B108 ∧ ¬High108 ⇒ O[T[3,10]]
B108 ∧ High108 ⇒ O[T≥10 ∪ L]
```

“敌”的法律含义、投敌行为及主体适格单列评价和解释接口；不能以一般境外就业或迁居直接替代。

## 第109条 叛逃

```text
B109.1 = 国家机关工作人员 ∧ 履行公务期间 ∧ 擅离岗位
         ∧ (叛逃境外 ∨ 在境外叛逃)
B109.1 ∧ ¬情节严重 ⇒ O[T≤5 ∪ D ∪ G ∪ PP]
B109.1 ∧ 情节严重 ⇒ O[T[5,10]]

B109.2 = 掌握国家秘密的国家工作人员
         ∧ (叛逃境外 ∨ 在境外叛逃)
B109.2 ⇒ O[依第一款规定从重处罚]
```

第二款按其明示的特殊主体和叛逃行为单列，不机械把第一款的“国家机关工作人员、履行公务期间、擅离岗位”全部复制进来。第93条的国家工作人员范围与本条第一款的国家机关工作人员不能混同。第113条排除本条死刑授权。

## 第110条 间谍行为

```text
Acts110 = 参加间谍组织
          ∨ 接受间谍组织及其代理人的任务
          ∨ 为敌人指示轰击目标
B110 = Acts110 ∧ 危害国家安全
B110 ∧ 情节较轻 ⇒ O[T[3,10]]
B110 ∧ 非较轻档 ⇒ O[T≥10 ∪ L]
```

“组织”“代理人”“任务”及危害国家安全须分别认定。反间谍行政调查认定不能直接替代刑法构成和刑诉证明标准。

## 第111条 为境外非法获取或提供国家秘密情报

```text
B111 = 为境外机构、组织或人员
       ∧ (窃取 ∨ 刺探 ∨ 收买 ∨ 非法提供)
         (国家秘密 ∨ 情报)
情节较轻 → T≤5 ∪ D ∪ G ∪ PP
普通档 → T[5,10]
情节特别严重 → T≥10 ∪ L
```

一般信息不当然属于国家秘密或刑法意义的情报。秘密性质、情报范围、境外对象、行为和主观罪过分别映射到证据；鉴定或认定意见不是无需审查的自动有罪标签。

## 第112条 战时资敌

```text
B112 = 战时 ∧ 向敌人供给(武器装备 ∨ 军用物资)资敌
B112 ∧ 情节较轻 ⇒ O[T[3,10]]
B112 ∧ 非较轻档 ⇒ O[T≥10 ∪ L]
```

战时属于独立适用条件。第451条文义是“本章所称战时”，本稿不未经核实即将其完整定义全局移植；本章适用的战时解释依据待法源任务核定。

## 第113条 死刑授权与没收财产

```text
DeathEligibleBase = {第102条, 第103条第一款, 第104条,
                     第108条, 第110条, 第111条, 第112条}
Special113 = 对国家和人民危害特别严重 ∧ 情节特别恶劣
基础罪属于DeathEligibleBase ∧ Special113
    ⇒ P[判处死刑]，仍受总则死刑条件、禁止和复核程序约束

成立本章任一犯罪 ⇒ P[并处没收财产]
```

排除集合为第103条第二款、第105条、第107条、第109条。不得把“可以”改写为必判死刑；“危害特别严重”与“情节特别恶劣”是合取。第106条不是独立基础罪。本条没收财产刑与第64条追缴、没收犯罪工具分别处理。
